# storerob
Model based store robbery
</br>
</br>
Robbery is based on the default 24/7 cash register model.
</br>
You can:
- Steal like normal
- Open the safe
- Take the register (Item needs to be added)
- Steal from the shelfs

</br>
Each one is model based execpt the safe.
</br>
So anywhere in your server they will be able to steal stuff
